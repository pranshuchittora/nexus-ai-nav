## 🚀 快速开始

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/boy80711/nexus-ai-nav.git
cd nexus-ai-nav

# 直接用浏览器打开
open index.html
# 或者用本地服务器
python3 -m http.server 8080
```

### GitHub Pages 部署

1. Fork 或 Clone 本仓库
2. 进入 Settings → Pages
3. Source 选择 `main` 分支，目录选 `/ (root)`
4. 保存后即可访问 `https://你的用户名.github.io/nexus-ai-nav/`
